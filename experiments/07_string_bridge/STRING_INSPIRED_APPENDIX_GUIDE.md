# String-Inspired Appendix Guide

This folder is intentionally preserved as a bridge for readers coming from string theory.

BST does **not** assume fundamental strings. The relevant claim is weaker and more useful:

> contact-loop and string-like modes can appear as emergent signatures of the beating substrate.

This makes the appendix a potential translation layer rather than a replacement for string theory. It is a way to ask whether some string-theoretic structures might be recoverable as effective modes of a deeper generative substrate.
